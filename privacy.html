Política de Privacidade - Zenith Bot

Esta política explica como o Zenith Bot trata os dados necessários para funcionar.

1. Dados que podem ser utilizados

O bot pode processar IDs de utilizadores, IDs de servidores, IDs de canais e informações relacionadas com comandos utilizados.

2. Utilização dos dados

Os dados são utilizados apenas para fornecer as funcionalidades do bot.

3. Partilha de dados

Os dados não são vendidos a terceiros.

4. Armazenamento

Alguns dados podem ser armazenados apenas quando necessário para o funcionamento do bot.

5. Remoção de dados

Os utilizadores podem pedir a remoção dos seus dados entrando em contacto com a equipa do Zenith.

Última atualização: 5 de outubro de 2026.
