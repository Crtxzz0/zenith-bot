Política de Privacidade

Zenith Bot · Última atualização: 5 de outubro de 2026

1. Introdução

Esta Política de Privacidade explica como o Zenith Bot pode recolher, processar e utilizar informações necessárias para o funcionamento das suas funcionalidades.

2. Dados que podem ser processados

O Zenith Bot pode processar informações como ID do utilizador, ID do servidor, ID dos canais e informações relacionadas com comandos utilizados no Discord.

3. Utilização dos Dados

As informações processadas são utilizadas apenas para fornecer as funcionalidades do bot, como moderação, tickets, comandos e configurações do servidor.

4. Armazenamento de Dados

Alguns dados podem ser armazenados quando forem necessários para manter configurações ou funcionalidades do Zenith Bot. Os dados que deixarem de ser necessários podem ser eliminados.

5. Partilha de Dados

O Zenith Bot não vende dados pessoais dos utilizadores. As informações não são partilhadas com terceiros para fins publicitários.

6. Segurança

São tomadas medidas razoáveis para proteger as informações utilizadas pelo bot contra acesso não autorizado ou utilização indevida.

7. Remoção de Dados

Os utilizadores podem pedir informações sobre os seus dados ou solicitar a sua remoção através da equipa do servidor Zenith.

8. Alterações a esta Política

Esta Política de Privacidade pode ser atualizada sempre que necessário. A versão mais recente estará disponível nesta página.

9. Contacto

Para questões relacionadas com privacidade ou utilização de dados, entra em contacto com a equipa Zenith através do servidor oficial no Discord.
